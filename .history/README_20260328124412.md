# Bionic PDF

A simple desktop app that transforms PDFs for faster, more focused reading — by bolding the first letter of every word.

This technique is inspired by [Bionic Reading](https://bionic-reading.com/), which is particularly helpful for people with ADHD or anyone who wants to read more efficiently.

![demo placeholder](pictures/app_demo_picture.png)

## How it works

1. Drop a PDF onto the app (or click "or browse")
2. The app overlays bold first letters on every word in the text layer
3. A new file is saved alongside the original as `filename_bionic.pdf`

Works well with papers, journals, news articles, and novels. Skips headers, footers, footnotes, and math/symbol glyphs automatically.

## Download

Grab the latest `.app` from [Releases](../../releases). Unzip and drag to `/Applications`.

> **First launch on macOS:** right-click → Open to bypass the Gatekeeper warning (the app is not signed with an Apple Developer certificate).

## Run from source

**Requirements:** Python 3.10+

```bash
git clone https://github.com/your-username/bionic-pdf.git
cd bionic-pdf
pip install -r requirements.txt
python app.py
```

## Build the .app yourself

```bash
pip install pyinstaller
pyinstaller --windowed --onedir --name "Bionic PDF" --collect-all fitz app.py
# output: dist/Bionic PDF.app
```

## Limitations

- Only works on PDFs with a real text layer. Scanned PDFs (image-only) are not supported.
- The bold overlay uses a matching system font (serif → Times Bold, sans-serif → Helvetica Bold, mono → Courier Bold). The font won't be pixel-perfect for every PDF, but is close enough for reading.
- Assumes a white page background.
